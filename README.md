# Eden Home Health Services

Marketing website for Eden Home Health Services LLC, a Texas non-medical home care agency.

Plain HTML, CSS and JavaScript with no build step. Open `index.html`, or deploy the folder to any static host.

- `index.html` — page content
- `css/styles.css` — brand colors and type are the tokens at the top of the file
- `js/main.js` — interactions; the `SITE` block at the top holds phone, email, hours, address, the form endpoint and the hero photo path
